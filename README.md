# aerOS
A browser-based operating system interface inspired by the Windows Aero aesthetic.
## Features
* Aero Glass-style setup window
* Animated particle-based boot screen
* "Welcome to aerOS" particle formation
* Fullscreen startup experience
* Light and dark appearance selection
* Wallpaper switching
* Smooth wallpaper cross-fade
* Custom username setup
* Date of birth setup
* 12-hour / 24-hour clock selection
* Aero-style minimize, maximize, and close buttons
* Animated glowing particles
* Responsive fullscreen canvas
## Requirements
* A modern web browser
* JavaScript enabled
* The project files kept in the correct folder structure

## Usage

1. Open `aeroOS.html`.
2. Wait for the aerOS logo to form.
3. Click anywhere on the screen.
4. The interface enters fullscreen mode.
5. Customize the setup options.
6. Choose between Light and Dark appearance.
7. Continue into aerOS.
